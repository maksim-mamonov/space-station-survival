# space-station-survival
Space Station Survival
Курсовой проект по дисциплине «Программирование».
Игра на выживание на космической станции, реализующая принципы ООП на языках C++ и C#.

Структура проекта:
src/cpp/ — модули и логика на языке C++
src/csharp/ — интерфейсная / логическая часть на C#
docs/ — документация и материалы курсовой работы
