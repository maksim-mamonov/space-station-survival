# Lab 02: Classes, Composition and Aggregation in C++

## Состав проекта
В папке содержатся исходные файлы лабораторной работы по ООП:
- `oxygen_tank.hpp` / `oxygen_tank.cpp` — класс кислородного баллона.
- `life_support_module.hpp` / `life_support_module.cpp` — класс модуля жизнеобеспечения (агрегация).
- `space_station.hpp` / `space_station.cpp` — класс космической станции (композиция).
- `main.cpp` — демонстрационная программа.

## Сборка и запуск
Вы можете открыть эти файлы в любой IDE для C++ (например, создать новый проект в Visual Studio / CLion, добавить туда эти файлы) и запустить `main.cpp`.
