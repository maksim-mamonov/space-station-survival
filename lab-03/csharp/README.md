# ЛР 3, часть 1. Перенос программы на C#

Программа ЛР 2 (космическая станция), перенесенная на C#: те же три класса, те же
методы предметной области и те же правила. Память освобождает сборщик мусора.

## Файлы

- `OxygenTank.cs` — кислородный баллон (правило: нельзя израсходовать больше, чем осталось).
- `LifeSupportModule.cs` — модуль жизнеобеспечения; баллон приходит снаружи (агрегация). Правило: нельзя запустить модуль без баллона.
- `SpaceStation.cs` — станция; модуль создается в ее конструкторе и наружу не отдается (композиция).
- `OxygenReading.cs` — структура «показание датчика» для сравнения `struct` и `class`.
- `OxygenLog.cs` — журнал расхода (`IDisposable`), закрывается при выходе из блока `using`.
- `MemoryDemo.cs` — демонстрации: ссылки и копии, освобождение ресурса, сборщик мусора.
- `Program.cs` — точка входа.

## Сборка и запуск

Нужен .NET SDK 8 или новее. Команды выполняются из корня репозитория:

```
dotnet build lab-03/csharp
dotnet run --project lab-03/csharp
```

Если в консоли Windows вместо русских букв вопросительные знаки, перед запуском выполните `chcp 65001`.
